# Archived: the character companion UI

Momo's first interface: a cherry-blossom chibi character on a table, with 2D/3D scenes, a character picker, spoken
replies and a scripted demo runtime. It was replaced by the Wispr-style dictation bar and Settings app (see
`docs/07_DICTATION_APP.md`). Nothing here is compiled or tested any more. It is kept so the work is not lost; copy a
file back into `src/` to bring it back.
